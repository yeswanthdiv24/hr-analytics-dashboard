# HR Analytics Dashboard

An interactive Tableau dashboard that analyzes employee attrition, demographics, job satisfaction, education, and workforce trends.

## Project Overview

This dashboard helps HR teams understand employee attrition patterns and identify areas that may need attention.

## Key KPIs

- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Employee Age: 37

## Dashboard Analysis

- Attrition by gender
- Department-wise attrition
- Employee count by age group
- Job satisfaction rating by job role
- Education field-wise attrition
- Attrition by age group and gender

## Tools Used

- Tableau
- Data cleaning and transformation
- Data visualization
- HR analytics
